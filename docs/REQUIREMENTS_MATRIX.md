# REQUIREMENTS_MATRIX.md — Skill and Requirement Tracking

This document tracks the target skills for junior/junior+ .NET backend roles, mapped against planned evidence and current progress. It is updated only when evidence actually exists — not in anticipation of it.

## Skill levels

* **0** — Not studied
* **1** — Can explain the purpose
* **2** — Can implement with guidance
* **3** — Can implement independently and test
* **4** — Can explain production behavior, failure modes and trade-offs

**Level 3 and Level 4 require recorded evidence.** A level without evidence must be capped at 2.

## Evidence types

* Commit
* Pull request
* Unit test
* Integration test
* Working endpoint
* Working user flow
* Deployment
* Load-test result
* ADR
* English technical explanation
* Debugging note
